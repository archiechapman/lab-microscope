First-time setup on Windows
  1. Install Zadig and plug in the microscope.
  2. Options → List All Devices, select the device with ID 1871 01B0.
  3. Choose WinUSB as the driver and press Replace Driver.
  4. Reload this page and press Connect.

On Linux, add a udev rule granting access to 1871:01b0. macOS needs nothing extra.
